# Feature Component Diagrams

These diagrams expand individual workflows inside the GUI container. They show repository-owned components by their implementation type and retain external processes, storage, web content, and Windows services at the boundary.

- [Configuration and Settings](configuration-and-settings.md): Startup initialization, edition and game profiles, executable paths, and persisted options.
- [Path Selection and Validation](path-selection-and-validation.md): File and folder selection, path normalization, validation, and output defaults.
- [Executable Discovery](executable-discovery.md): Cancellable fixed-drive search and Legacy or Current classification.
- [Champollion Execution and Diagnostics](champollion-execution.md): Confirmation, request creation, argument construction, process execution, progress, and diagnostic logs.
- [Output and Desktop Actions](output-and-desktop-actions.md): Live output, clipboard copy, and File Explorer navigation.
- [Help Browser and About Documents](help-and-about.md): Embedded Nexus Mods pages and packaged legal-document handling.

See the [Unified Component Diagram](../unified-component-diagram.md) for the complete component relationship in one view.
